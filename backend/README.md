# Sheetly API

İlk hafta API temeli: sağlık kontrolü, kayıt/giriş oturumları ve güvenli XLSX/CSV önizleme uçları.

Yerel çalıştırma: `dotnet run --project Sheetly.Api`

> Oturum deposu ilk hafta prototipi için bellektedir. Production aşamasında PostgreSQL ve süreli token deposuyla değiştirilecektir.
